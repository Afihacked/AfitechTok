# AfitechTok

AfitechTok — aplikasi sederhana untuk mendownload video, music & foto kualitas HD dari TikTok dan menyimpan story WhatsApp tanpa watermark.

Fitur:
- Download video TikTok tanpa watermark
- Download Music TikTok
- Download foto TikTok
- Download story WhatsApp
- Riwayat unduhan
- Kompatibel dengan Android terbaru
- Penyimpanan Otomatis dan mendukung android terbaru

Untuk dokumentasi lebih lengkap periksa repo GitHub:
https://github.com/Afihacked/AfitechTok
